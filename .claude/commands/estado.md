3. Responde en este formato, breve:
   - 📍 **Estás en:** fase, tarea y avance (%)
   - ✅ **Lo último que se hizo:** 
   - ⏭️ **Lo que sigue:** los próximos 3 pasos y qué comando usar
   - ⛔ **Bloqueos o decisiones pendientes tuyas:** 
   - 📥 **Bandeja:** N cambios sin clasificar
   - 💾 **Git:** todo guardado / hay cambios sin commit / sin push
4. Si ESTADO está desactualizado respecto de Git o de la bitácora, corrígelo y avisa.
