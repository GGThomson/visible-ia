## Checklist técnico
- [ ] Pruebas completas pasan en CI
- [ ] Variables de entorno de producción configuradas (fuera de Git)
- [ ] Copias de seguridad de la base de datos
- [ ] Monitoreo de errores y registros (logs)
- [ ] Dominio, HTTPS
- [ ] Plan de reversa (*rollback*) probado
- [ ] Tag de versión `v1.0.0` y *release* en GitHub con notas

## Checklist de negocio (según el tipo)
- [ ] Términos y privacidad publicados (SaaS / Móvil)
- [ ] Pagos probados en modo real (SaaS)
- [ ] Página de venta y analítica (SaaS / Contenido)
- [ ] Acta de aceptación firmada por el cliente o el responsable (Empresa / Freelance)
- [ ] Manual de uso o capacitación (Empresa / Interna)
- [ ] Envío a tiendas (Móvil / Extensión)
