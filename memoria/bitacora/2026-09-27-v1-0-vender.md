## Problemas y cómo se resolvieron
- Google devolvía "Alcanzaste el límite…" como respuesta → ahora es una falla que se reintenta; Google corre de a 1.
- La CLI no confirmaba cada respuesta (se perdió 1 crédito) → conexiones `autocommit` en comandos largos.
- Prompt v1 del extractor descartaba todo con razonamiento mínimo → prompt v2.
- Asociación: uniones falsas por contención ("Digital Smiles" ≠ "Smiles Peru") y nombres con dos alias → reglas corregidas con pruebas.
- Secrets de GitHub con un valor equivocado → los 13 recargados desde `.env` sin mostrar valores.
